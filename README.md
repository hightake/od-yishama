# קופת עוד ישמע

מצגת קולנועית לדינר שש שנים לקופת "עוד ישמע".

פותחים את `index.html` בדפדפן (Chrome מומלץ), לוחצים "התחלת המצגת" והיא רצה לבד במסך מלא.

- רווח / חץ שמאלה: השקף הבא
- חץ ימינה: השקף הקודם
- P: השהיה / המשך
- F: מסך מלא

הנתונים (שמות וסכומים) נמצאים בראש הסקריפט בקובץ, במערך `donors`.
